ExperienceGraph 状态匹配可视化

这页把“经验 + 探索”的记忆机制画成可交互图：节点表示可复用的条件集合，边表示动作，路径记录表示从某个条件出发到目标成功的历史证据。

节点

不是完整环境状态，而是当前决策需要的条件签名。

匹配

当前 observation 满足条件，且目标上下文一致。

展示

给 agent 下一步动作、短路径和统计证据。

Condition signature

    ExperienceView 建议格式

    被拒绝的相似经验

    为什么不用完整状态相等 完整状态会把无关物品也算进去，例如 gold block 任务里多了 apple，不应该让经验失效。
    为什么不用文本相似直接匹配 diamond chestplate 和 gold block 都是矿物 craft，但目标、数量、材料都不同，不能把经验当成同一个状态。
    为什么路径比单步次数有用 下一步告诉 agent 现在做什么，短路径告诉它这个动作通向哪个结果，统计证据给出历史可靠度。
    探索怎样进入图谱 没有匹配经验时 agent 自由探索；成功后记录 start condition、actions、result，下次满足条件时才展示。
    跨任务复用的边界 一个任务的成功结果可以成为另一个任务的子目标条件，例如 iron_ingot x3 可以服务于 iron_pickaxe。
